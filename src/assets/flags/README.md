# Flag icons

Bundled 4x3 SVGs from [lipis/flag-icons](https://github.com/lipis/flag-icons)
(MIT, © Panayiotis Lipiridis). Local assets instead of regional-indicator
emoji: Android renders flag emoji inconsistently and some fonts fall back to
bare letter pairs.

Add a currency to `src/domain/currency.ts` → `CURRENCY_FLAGS` and drop the
matching `<iso2>.svg` here.
